# Nordic Onboarding

Account opening for a Nordic savings and investment platform that launches in a
second country without forking the code. Sweden and Denmark run through one
onboarding flow; everything that differs between them lives in a market module.

> Work in progress. A portfolio project: not affiliated with any bank, product
> rules are simplified and illustrative, and eID login is simulated.

## Layout

- `backend/` – Java 25, Spring Boot 4
- `frontend/` – Angular 21 (coming in stage 3)
